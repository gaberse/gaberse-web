# Gaberse Codex handoff package

Copy these files into the root of `gaberse-web`:

```text
GABERSE-HANDOFF.md
AGENTS.md
CODEX-START-PROMPT.md
docs/
  PRODUCT-BLUEPRINT.md
  DESIGN-SYSTEM.md
  CONTENT-MODEL.md
  IMPLEMENTATION-PLAN.md
```

Then open the repository in Codex and paste the contents of `CODEX-START-PROMPT.md` as the first instruction.

Do not let the first Codex session scaffold the app before it has read the handoff and proposed the architecture.
